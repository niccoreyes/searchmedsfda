About Rx Builder

A local-first, offline prescription builder with FDA Philippines drug search.

How It Works

This web application provides a fast, local drug search and prescription builder. It can load drug data in two ways:

  • FHIR Server (Online): Connects to a FHIR terminology server to fetch the latest FDA drug data using FHIR standard APIs
  • CSV File (Offline): Load a local CSV file from the FDA Philippines Verification Portal for offline use

Once loaded, all drug searches happen locally in your browser for instant results. Build prescriptions, add custom medications, and print or save as PDF.

FHIR Terminology Server

This app queries drug data using the FHIR (Fast Healthcare Interoperability Resources) standard. It fetches concepts from a CodeSystem resource which contains all drug properties (generic name, brand name, strength, form, classification, manufacturer, etc.) and validates codes against a ValueSet for the complete FDA Philippines drug database.

The terminology server is powered by Ontoserver on FHIRLab by the SSCP project (Strengthening Standards Capability Project), a capacity development program for Digital Health Standards and Interoperability in the Southeast Asia and Pacific Region.

How to Use

  1. Click "Load from FHIR Server" for online data, or load a local CSV file
  2. Search for drugs using the search tab
  3. Build prescriptions in the Rx tab
  4. Print or save as PDF when done

Privacy

All processing happens locally in your browser. No data is ever uploaded to any server. Your prescriptions are saved to your browser's local storage only.

Tips

  • Use cross-field search: type "Amlo Exfo" to find Amlodipine (generic) + Exforge (brand)
  • Save drafts locally before printing
  • Works completely offline after loading the CSV

Data source: FDA Philippines Drug Products Database
